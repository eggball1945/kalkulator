## ⭐ **About the Project**

This project is a graphical calculator application built using **Python** and the **Kivy Framework**.  
It supports basic arithmetic operations and features a clean, responsive interface suitable for both desktop and mobile.

## 🚀 **Features**

- ✨ Modern UI built with Kivy  
- ➕➖✖️➗ Basic arithmetic operations  
- ⚡ Real-time screen updates  
- 🛡️ Error handling (e.g., divide by zero)  
- 📱 Cross-platform (Windows, Linux, macOS, Android)

## 🛠️ **Installation Guide**

### **1. Clone the Repository**
```bash
git clone https://github.com/username/calculator-kivy.git
cd calculator-kivy
```

### 2. Create Virtual Environment ###

```bash
python3 -m venv kalkulator_env
```

3. Activate the Environment
🔹 Linux / macOS
```bash
source kalkulator_env/bin/activate
```
🔹 Windows
powershell
```bash
kalkulator_env\Scripts\Activate
```

4. Install Dependencies
```bash
pip install kivy
```

▶️ Running the App
After the virtual environment is activated:

```bash
python main.py
```
Or
```bash
python3 main.py
```
The calculator window should now appear on your screen.
